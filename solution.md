# Assignment 1.5 — GitHub Essentials II

## Objective

Upload a local project to GitHub.

## Tasks Completed

1. Created a GitHub account.
2. Created a new public repository.
3. Connected the local repository to the remote repository.
4. Uploaded project files using `git push`.
5. Added a new file and pushed the second commit.
6. Verified the commit history on GitHub.

## Git Commands Used

bash

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/assignment-1.5-github-essentials.git
git push -u origin main
```

## Second Commit

bash

```bash
git add .
git commit -m "Add second file"
git push
```

## Result

Successfully uploaded the project to GitHub with two commits.

The public repository contains the project files and verified commit history.
